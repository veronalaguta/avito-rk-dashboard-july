### Исправление анализа превью

Уточнено правило: превью оцениваем только по CTR, потому что превью влияет на переход из показа в просмотр.

Правильная метрика:
- CTR превью = просмотры / показы.

Из анализа превью убраны:
- контакты;
- CR в контакт;
- цена контакта;
- звонки;
- заказы;
- цена заказа.

### Проблема одинаковых превью

Было замечено, что визуально одинаковые превью показывались отдельными карточками.

Причина: группировка шла по локальному пути картинки, а не по визуальной идентичности. Одна и та же картинка могла быть скачана под разными именами для разных объявлений.

Исправление:
- добавлен ручной `previewKey` для пилотного набора;
- группировка теперь идет по `previewKey`, если он указан.

Следующее более правильное решение:
- группировать по каноническому URL первого изображения;
- либо скачивать картинки и считать perceptual hash.
